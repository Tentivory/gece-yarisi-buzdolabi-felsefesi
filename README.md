# Gece Yarısı Buzdolabı Felsefesi

Bu repository, insanlığın en büyük sorularından birine cevap arar: **Gece yarısı açılan buzdolabı ne düşünüyor?**

## Nedir Bu Saçmalık?

`fridge_philosopher.py` adlı script, buzdolabınızı açtığınızda (aslında her çalıştırdığınızda) onunla derin, anlamsız ve varoluşsal bir sohbet başlatır. Buzdolabı açılır, ışık yanar, felsefe başlar. Kapanmaz. Çünkü kapanmak ölümdür, açık kalmak ise açlıktır.

### Nasıl Çalıştırılır?

```bash
python fridge_philosopher.py
```

Script sonsuz döngüye girer. Ctrl+C ile kurtulabilirsiniz. Belki. Buzdolabı affetmez.

## Özellikler

- Gerçek zamanlı (yani print) diyalog
- Rastgele varoluşsal krizler
- Açlık seviyesi artar ama asla bitmez
- Hiçbir şey yapmaz ama her şeyi sorgular

## Neden?

Çünkü saat 03:17'de buzdolabı açmak bir tercihtir. Tercih ise özgürlüktür. Özgürlük ise açık buzdolabıdır.
